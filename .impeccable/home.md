# Precedent homepage

Mode is Experience.

The homepage follows an on-call decision. An API gateway alert leads to a close text match. A saved edge leads to a registry incident with a shared fix and a suggested configuration check. A separate repository mirror replay lets the reader see which incident comes back after a responder saves a resolution.

Warm black, orange, Bricolage Grotesque, IBM Plex Mono, and Streamline Pixel icons give the story and console a shared identity. Keep symptoms, incident IDs, the relationship, and the responder's next step visible in the copy. Let the Three.js field cluster by meaning and draw the evidence and learned links in response to the controls.

The first viewport pairs the incident-memory promise with the gateway 503 signal and a direct console link. The evidence and replay each open the corresponding analysis sample. Reduced motion removes stagger, pointer tilt, and idle orbit. Case data are synthetic and the geometry is illustrative.
