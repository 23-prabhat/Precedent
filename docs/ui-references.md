# Precedent UI references

The supplied `precedent-home.html` informed the warm black palette and orange signal paths. The homepage uses a full-bleed Three.js particle field and a shared scroll timeline. The Canvas 2D fallback uses the same projected geometry and recorded incident links.

- The continuous scene and the way copy appears within it draw from [Rocani’s Outreach](https://rocani.studio/work/outreach), an Awwwards Site of the Day, and the [MotionSites gallery](https://motionsites.ai/).
- The opening splits and staggers words in the style of [React Bits Split Text](https://reactbits.dev/text-animations/split-text). The vector chapter uses a scroll-synced text mask informed by [21st’s scroll word reveal](https://docs.21st.dev/%40motiondotdev/components/motion-scroll-word-reveal). Motion for React drives both treatments and shares its scroll value with the particle field.
- The graph controls and example switcher draw on the interaction patterns in the [Framer motion gallery](https://www.framer.com/marketplace/components/tags/motion/).

Interface icons are from [Pixel Mono Free by Streamline](https://www.streamlinehq.com/icons/pixel) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The selected SVGs are served locally.
